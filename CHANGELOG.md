## [1.0.0] - 2026-03-23

### Added

- WinForms GUI (dark theme, cards, status bar).
- Process list with search and refresh.
- TCP and UDP sockets (IPv4 and IPv6) per PID via iphlpapi extended tables.
- Grid: protocol, local/remote endpoints, state; refresh about every 2 seconds.
- Text dump (UTF-8) with Proto/Local/Remote, UNIQUE_IP and UNIQUE_UDP_BIND lines.
- Launch external .exe with arguments and auto-dump for child PID.
- Single-file publish profiles for Visual Studio (win-x64 FDD and self-contained).
- MIT LICENSE, README, CONTRIBUTING, RELEASING docs.
